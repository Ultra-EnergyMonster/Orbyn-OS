# Contributing

Thanks for helping with this independent OS project. The repository is public, but the project licence is currently undecided; see `LICENCE-STATUS.md` before redistributing or reusing code.

## Contributions

- Read `AGENTS.md` and the relevant architecture decision records.
- Open an issue or draft proposal for significant architecture/API changes.
- Work on a feature branch and make focused commits.
- Include tests and documentation for behavioural changes.
- Describe exactly which commands ran and which tests did not run.
- Do not submit proprietary Windows code/assets, binaries with unclear provenance, secrets, or firmware that cannot be redistributed.
- Do not claim hardware or Windows application compatibility without reproducible evidence.
- Do not run untrusted code with repository secrets or privileged CI permissions.

## Pull requests should include

- Purpose and scope.
- Architecture and security implications.
- Tests run, with environment/commands.
- Tests not run and blockers.
- Compatibility/limitations.
- Screenshots only for real UI behaviour, labelled with the actual build/test environment.
